# Dependencies for the Vercel deployment, which builds from the repository root.
#
# The Docker image does not read this file. It installs backend/pyproject.toml
# directly, because its build context is backend/ and it has no root to build
# from. This file exists so that a platform pointed at the repository root
# installs the same thing.
#
# The backend as a local package, so its own pyproject.toml stays the single
# list of what the application needs and nothing is restated here to drift.
./backend

# Named again, and deliberately without a version, so that the platform can see
# which framework this is. Vercel picks its Python framework preset by looking
# for a known dependency by name, and a local path tells it nothing. The version
# still comes from backend/pyproject.toml, which pip resolves; this line only
# has to be readable.
fastapi
